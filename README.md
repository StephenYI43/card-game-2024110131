# 实验六 多 Fragment 应用

作者：宋珺熠 2024110131。此工程基于实验五的 Dev，在 Frag 分支开发；main 和 Dev 保留。

- 单 Activity 承载个人资料、双牌、三牌三个 Fragment。
- 两套牌局分别使用 16、24 张牌，独立计分、匹配、重开。
- 个人资料和牌局快照序列化到应用私有文件。退出后可恢复资料、牌面、分数和翻牌次数。
- Android 15 模拟器完成强停恢复测试；25 项单元测试通过。

Android Studio 打开本目录，使用 SDK 35 构建。实验六报告位于 docs，运行截图位于 report-assets/lab6。历史实验四、五版本仍可从原分支或标签查看。
